# 第一轮实现与前10秒测试报告

本报告记录首轮35°转头阈值、30°跳变阈值的历史测试。模型和视频现已复制到本项目，配置使用相对路径，运行使用本项目 `.venv`。用户当前设置为40°转头阈值、40°跳变阈值，迁移验证结果另见 `outputs/local_models_axis30_turn40/summary.json`。

后续站立过滤原图复核确认此前产生两次事件的P10实际处于站立。本报告的旧事件未排除站立，不代表新的过滤结果；最新实现和验证见 `standing_filter_report.md`。

已完成固定二维参考轴转头识别，在指定视频前10秒逐帧运行，并保存视频、逐帧CSV、事件CSV、配置快照和抽帧。以下事件是当前规则确认结果，尚未建立人工真值，不能将2次事件直接当成准确率结论。

1. **旧项目参考模块**：实际工程里没有要求中举例的 `pose_core.py/facing.py/enhance.py`；使用功能对应的 `body_head_detector.py`、`head_pose_detector.py`、`upstream.py`、`person_tracker.py`。核对了 `head_hand_geometry.py` 的二维矩阵投影约定，仅参考该函数，不导入其业务模块。

2. **新建文件**：根目录 `main.py/config.yaml/README.md/memory.md/requirements.txt/report.md/audit_run.py/.gitignore`；`src/__init__.py/detector.py/head_pose.py/upstream.py/head_direction.py/tracker.py/turn_detector.py/visualizer.py/pipeline.py`；`tests/test_head_direction.py/test_turn_detector.py`；`weights/README.md`。保留已有 `turnhead/` 子目录不动，新实现从根目录运行。后续迁移增加本地 `BPJDet/SemiUHPE`，`weights/videos` 已包含模型权重和视频，以及相对路径快照测试 `tests/test_config_paths.py`。

3. **模型复用**：读取旧项目 BPJDet 与 SemiUHPE 仓库及原有两份权重，使用旧 `.venv` 的 PyTorch 2.7.0+cu118 与 GTX1060。BPJDet 输出人体框和关联头框；SemiUHPE 保持原图裁头、224×224预处理、student权重和原有rotation/yaw/pitch/roll转换。未下载或训练模型。

4. **二维方向**：`R @ [0,0,1]` 得到forward向量，取x/y，计算原始投影长度后归一化。角度 `degrees(atan2(dy,dx)) % 360`，右0°、下90°、左180°、上270°。不对投影矩阵转置，不改变符号，不除以z。Euler诊断转换保留旧约定。

5. **参考轴夹角**：`abs(((head_angle-axis_angle+90)%180)-90)`，全局轴使用30°。30°和210°都得到0°差。参考轴画成穿过头中心的双向直线，实际头方向画箭头。

6. **范围为什么为0～90°**：模180°将相反射线视为同一条轴，把有符号差折回[-90°,90°)，再取绝对值。单元测试遍历角度范围，真实CSV也检查了所有原始/平滑轴差，均在范围内。

7. **平滑**：每个人独立维护最近5个接受的二维单位向量，求均值后重新归一化，重新计算角度。平均向量过短时无效，不普通平均角度，359°/1°不会变180°。

8. **跳变过滤**：原始方向与候选平滑方向相对上一有效方向的圆周变化分别检查，任一>30°则记POSE_JUMP，保留CSV，不入窗口、不更新状态。该规则避免5帧平滑将突跳摊成假连续转头。无效帧及有效样本间隔>0.2秒清除连续路径/持续时间证据；无效帧冻结显示状态，未确认事件者恢复后重新获取正常状态。投影<0.12、abs(pitch)>=90°和无姿态也过滤。

9. **状态机**：UNKNOWN在≤10°稳定0.4秒后成为NORMAL；离开10°且最近窗口总体增大至少2°成为TURNING；连续路径到≥35°稳定0.4秒成为TURNED；最近窗口总体减小至少2°成为RETURNING；回到≤10°稳定0.4秒重新NORMAL。允许小抖动，不要求逐帧单调。RETURNING若重新增大达到35°可回TURNED，不重复触发事件。起始姿态远离轴时保持UNKNOWN，不能凭一段大夹角直接认定转头。

10. **TURN_EVENT条件**：已有稳定NORMAL起点，经过TURNING，至少3个连续路径样本、跳变不过限、样本没有无效中断，≥35°持续0.4秒，才确认一次事件。每次TURNED只确认一次，回NORMAL后再允许下一次。事件包含编号、起止/确认时刻、角度、确认前最大轴差、时长、累计有符号方向变化及状态序列；NORMAL锁定active_reference_ray，事件过程中保持。方向仅作为诊断字段。

11. **测试结果**：13项unittest全部通过，包含题定轴角样例、范围、359°/1°、相反向量抵消、矩阵第三列约定、投影与pitch过滤、正常稳定、平滑转头、持续超过35°、回正与第二事件、初始大角度、瞬时跳变、被平滑隐藏的原始尖峰、无效帧/缺失间隔和两排相反朝向。另对真实CSV逐事件检查起点NORMAL、终点TURNED、路径有效、原始和平滑跳变不过限、无缺失间隔、阈值持续时间和事件ID唯一。

12. **真实短视频结果**：输入 `videos/教室前中_左_802监控_20260830130816_20260830133147_1530775.mp4`；原图3840×2160，20FPS，前10秒共200帧，未抽帧推理。输出视频1920×1080、20FPS，经完整解码确认200帧。推理及写入约76.4秒，人物记录4978条，临时ID累计34个（不是34名独立人员）。

13. **最主要问题**：30°是指定实验轴，没有经过本机位人工核对；人物自然朝向存在差异。OUT_OF_SCOPE占21.3%，会打断连续证据；UNKNOWN占72.7%，说明许多人缺少足够稳定的近轴起点。P10第二事件6.50s投影长度约0.158，虽高于0.12阈值但偏短，因此二维角度对小头姿变化较敏感；二维投影角变化不等于三维yaw旋转幅度。IOU跟踪也有遮挡、走动导致ID切换的限制。下一步应人工观看完整标注片段并核对参考轴、头姿质量及这两次事件；本轮未自动调轴或增加其它业务。
