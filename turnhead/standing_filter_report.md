# 站立排除实现与验证

本项目已加入独立站立过滤：BPJDet检测并分配人物ID → 站立特征与时序判断 → 排除站立者 → SemiUHPE及原有转头状态机处理其余人。未导入、调用或启动站立发布包接口。头向仍按原rotation matrix和人工30°参考轴计算，用户40°转头阈值/40°跳变阈值保留。

## 参考与本地实现

参考发布包 `stand_detector.py` 的六项几何特征、可见证据覆盖率、均值+EMA和0.80精度门槛；`temporal.py` 的三态因果窗口；`perspective.py` 的同机位透视压缩补偿原则。独立实现于本项目 `src/standing.py`、`src/standing_perspective.py`，没有复制其业务接口、ByteTrack、补框/重检或视频I/O流程。使用现有BPJDet人物ID，一对一最大IOU匹配姿态框，避免混用人物历史。

站立发布包的 `yolo26s-pose.pt` 已复制到 `weights/`。该模型仅提供站立几何的17个关键点，不用于头向、手部或其他行为。ultralytics8.4.137及必要依赖已装入本项目.venv；pip check通过，不需要外部工程或服务。

六项特征：躯干竖直度、髋踝跨度/躯干长度、膝角、头踝伸展/躯干长度、框高宽比、髋踝跨度/框高。可见特征加权评分；证据覆盖不足0.30或缺少腿部证据时UNKNOWN。默认15帧均值与EMA各半、alpha0.35；38帧三态窗口，S0非站立/S1过渡/S2站立，阈值0.60/0.45、stay0.92、sigma0.15。至少2个有效观测，S2且平滑分数≥0.80才排除。短缺失最多保持0.6秒；超过有效采样间隔0.2秒重新建立站立证据。

## 过滤行为

- 确认站立的人不进入SemiUHPE批次，不计算二维头向，不推进转头状态机。
- 立即清除其方向历史、正常起点、未完成转头路径和当前事件锁。已保存事件及编号保留。
- 重新坐下后从UNKNOWN获取新的稳定NORMAL，防止把站立前后的方向拼成转头事件。
- 画面保留人物框，标签 `STANDING / TURN SKIPPED`，不画参考轴或头向箭头。
- CSV保存站立分数、覆盖、S状态、匹配框/IOU、几何特征和透视系数。排除原因STANDING，transition_status=EXCLUDED_STANDING，头姿/方向为空，转头state=UNKNOWN，当前event_id为空。

这些参数在 `config.yaml` 的 `standing_filter` 部分。设置 `enabled: false` 即可关闭站立过滤。运行命令保持：

```powershell
.\.venv\Scripts\python.exe main.py
```

## 实际验证

原视频前10秒，3840×2160、20FPS，完整处理200帧、4978条人物记录。

第一轮无透视补偿：排除433条。近处P1原图确认站立，但2.00s原始分数约0.721，低于0.80过滤门槛。按参考算法的透视原则，从同一测试片段665个完整覆盖、膝角≥160°、躯干≤30°的模型样本拟合33个断点，保存为本地 `standing_perspective.json`。只放大腿跨度、全身伸展与框高宽比，系数1～2；上方区域不变。曲线限定视频文件名及分辨率，换视频时自动不补偿，不改变转头参考轴。

最终结果 `outputs/standing_filter_first10s_final/`：

| 项目 | 结果 |
|---|---:|
| 已过滤的站立人物记录 | 688 |
| 临时ID曾被站立过滤 | 8个 |
| 实际SemiUHPE人物调用 | 4058 |
| 转头事件 | 0 |
| 输出视频完整解码 | 200帧 |
| 单元/集成测试 | 31项通过 |

688条排除记录全部自动核验：yaw、head_angle、smoothed_head_angle及event_id为空；state=UNKNOWN；排除原因/transition_status正确。标注视频已完整解码，抽帧检查2.00s的近处P1和其他站立者已有过滤标记。8个ID是临时轨迹，不是8名不同的人。

之前P10的两次转头事件，在原图头部至脚部裁剪和关键点复核后确认该人实际站立，因此新的零事件结果符合“站立者不判断转头”的过滤要求。这不是新的准确率结论，原来的报告已标注这一后续修正。

## 限制

站立判断有冷启动和确认延迟；低分、姿态误解、腿部长期遮挡或画面截断时可能回到UNKNOWN，不能保证所有物理站立者始终被排除。尤其P1在近边缘/截断时仍可能漏过滤；本片段最终仅77条P1记录通过站立过滤，不代表完整过滤了该人全程。IOU人物ID切换也可能重新启动确认过程。短遮挡保持预算有限，避免永久沿用过期站立状态。

透视曲线由本视频模型样本拟合，用同一视频复测属于功能验证，未建立独立人工标注真值。不同机位/视频不能直接宣称具有相同效果。当前未移植发布包复杂的近距重检、失踪补检和ID继承，以保持过滤与原有转头流程独立且可检查。
